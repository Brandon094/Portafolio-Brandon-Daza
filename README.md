# 📱 Ecosistema Digital | Brandon Daza - Software Architect

✨ **Transformando visiones estratégicas en infraestructuras digitales de alto rendimiento.**

Este repositorio contiene la plataforma digital unificada de **Brandon Daza** y **ChopCode Solutions**. Diseñada bajo estándares de ingeniería de grado industrial, aplicando arquitecturas desacopladas y una experiencia de usuario inmersiva (Scrollytelling).

## 🚀 Versión 5.5 (Performance & PWA Edition)

### 🏆 Logros de Ingeniería
- **Arquitectura MVVM**: Capa de lógica desacoplada mediante Custom Hooks.
- **Scrollytelling 3D**: Experiencia cinematográfica en el eje Z optimizada por GPU (60 FPS).
- **Infinite Auto-Marquee**: Galería de proyectos autónoma con pausa inteligente.
- **Dossier Técnico**: Modales inmersivos inyectados vía React Portals para auditoría técnica.
- **Soporte PWA**: Instalable como aplicación nativa en dispositivos móviles.
- **Centro de Mando v4.5**: Panel administrativo avanzado con telemetría en tiempo real.

## 🛠️ Stack Tecnológico
- **Frontend**: React 18, TypeScript, Vite.
- **Diseño**: Tailwind CSS (Atomic Design), Framer Motion (Hardware Accelerated).
- **BaaS**: Firebase (Realtime Database, Authentication, Hosting).
- **Iconografía**: Lucide React.
- **PWA**: Vite Plugin PWA con Service Workers.

## 📂 El Ecosistema "Go"
Una red interconectada diseñada para potenciar la productividad rural y urbana:
1. **RutaGo**: Smart Mobility Engine.
2. **AgroGo**: Agricultural ERP (Offline-First).
3. **CargoGo**: Logistics & Auction Network.

## ⚙️ Instalación y Despliegue

1. **Clonar repositorio:**
   ```bash
   git clone https://github.com/Brandon094/portafolio-brandon-daza.git
   ```
2. **Instalar dependencias:**
   ```bash
   npm install
   ```
3. **Ejecutar en desarrollo:**
   ```bash
   npm run dev
   ```
4. **Compilar y Desplegar:**
   ```bash
   npm run build
   npx firebase deploy --only hosting
   ```
