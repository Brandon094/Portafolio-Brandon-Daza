# Sistema de Diseño: Violet Stealth Premium v7.5

El ecosistema visual de Brandon Daza evoluciona hacia el **Functional Branding**, donde la estética minimalista se une a la visualización técnica.

---

## 1. Fundamentos Visuales

- **Color Primario:** `#8B5CF6` (Violeta Vital). 
- **Acentos:** Cyan Neón y Esmeralda.
- **Textura:** Grainy Noise SVG embebido en CSS.
- **Gradiente:** White -> Violet -> Cyan (Energía Digital).

---

## 2. Estrategias de Interacción (UX)

### 2.1 Functional Graphics Preview
- **Concepto:** Las tarjetas ya no son galerías; son **Banners de Misión**.
- **Efecto Escáner:** Una línea láser neón recorre la imagen al pasar el mouse, sugiriendo un análisis de funciones en curso.

### 2.2 Dossiers Técnicos (Modales v2.0)
- **Visualización Adaptativa:** Protocolo `object-contain` para paridad visual entre capturas móviles y desktop.
- **Glass-Depth Ambient:** El fondo del modal reacciona dinámicamente al color de la imagen activa mediante un desenfoque (blur) del 10%.
- **Navegación Digital:** Contador de activos `01 / 05` y controles de búnker.

### 2.3 Simetría de Ingeniería
Uso de contenedores con altura fija (`h-14`, `h-20`, `h-24`) para garantizar que todas las tarjetas de proyecto estén perfectamente alineadas, proyectando orden y rigor.

---

## 3. Ergonomía Adaptativa

- **Smart Hybrid:** Cambio automático entre Píldora Superior y Bottom Dock según el dispositivo, priorizando siempre el rango de acción del pulgar.
