# Ficha Técnica - Ecosistema Digital Brandon Daza & ChopCode Solutions v6.0

## 🏗️ Arquitectura de Software (Nivel Senior Staff)

El proyecto ha sido consolidado como un ecosistema multiplataforma unificado, bajo una estética **"Violet Stealth Premium"**, optimizado para la máxima conversión y autoridad técnica.

### 1. MVVM & Progressive Web App (PWA)
- **Model:** Persistencia NoSQL en **Firebase Realtime Database** sincronizada mediante WebSockets para latencia ultra-baja.
- **ViewModel:** Capa de lógica desacoplada en Hooks.
    - `ScrollToTop`: Controlador de ciclo de vida para reset de navegación.
    - `useAnalytics`: Motor de telemetría propio (Engagement & Visits).
- **View (Atomic & Mobile-First):** 
    - **Smart Hybrid Navigation:** Sistema dual que conmuta entre una **Píldora Flotante Superior** en Desktop y un **Dock Ergonómico Inferior** en dispositivos móviles para optimizar la navegación con el pulgar.
    - **Dumb Components:** Átomos y Organismos 100% presentacionales.

### 2. Experiencia de Usuario "Elite" (UX/UI)
- **Violet Stealth System:** Estética minimalista basada en negro profundo, texturas de grano orgánico inyectadas vía SVG base64 (Zero-HTTP request).
- **Interactive Dock:** Barra de navegación móvil con feedback táctil (scaling), etiquetas compactas e indicadores de estado neón.
- **ChopCode Academy:** Terminal educativa integrada con catálogo de cursos y laboratorio de algoritmos.
- **Dossier Técnico (Modales):** Análisis arquitectónico profundo inyectado vía **React Portals** con scroll horizontal automático en títulos y acciones directas (Web/App).

### 3. El Ecosistema "Go" (Master Plan v1.9.10)
- **Centralización SSO:** Unificación de identidad bajo Firebase Auth.
- **Data Híbrida:** Uso estratégico de Realtime DB (RutaGo) y Cloud Firestore (AgroGo/CargoGo).

## 🛠️ Stack Tecnológico Definitivo
- **Core:** React 18 + Vite + TypeScript.
- **Estilos:** Tailwind CSS (Optimización JIT & Mesh Gradients).
- **Animaciones:** Framer Motion (Hardware Accelerated).
- **Backend:** Firebase (RTDB + Auth + Hosting).
- **PWA:** Vite Plugin PWA (Workbox).

## 🚀 Optimizaciones de Rendimiento (Ultra Smooth)
- **GPU-First Design:** Propiedades CSS que fuerzan la aceleración por hardware (`will-change`).
- **Scrollytelling Optimization:** Reducción estratégica del factor de escala (15x max) para prevenir saturación de memoria.
- **Mobile-First Audit:** Tipografía adaptativa y navegación orientada al pulgar (Bottom Dock).
