# Ficha Técnica - Ecosistema Digital Brandon Daza & ChopCode Solutions v7.5

## 🏗️ Arquitectura de Software (Nivel Senior Staff)

El proyecto ha evolucionado a un ecosistema multiplataforma unificado, optimizado para la máxima conversión y autoridad técnica, bajo la estrategia visual de **Functional Branding**.

### 1. MVVM & Progressive Web App (PWA)
- **Model:** Persistencia NoSQL en **Firebase Realtime Database** sincronizada mediante WebSockets.
- **Service Workers:** Soporte Offline-First y caché inteligente.
- **ViewModel:** Capa de lógica desacoplada en Hooks para gestión de telemetría y estado de navegación.

### 2. Experiencia de Usuario "Elite" (UX/UI)
- **Violet Stealth System:** Estética minimalista basada en negro profundo y texturas de grano orgánico.
- **Functional Graphics Preview:** Las tarjetas de proyecto ahora utilizan un sistema de previsualización basado en **Feature Graphics** (Banners de alta fidelidad), ocultando la galería interna para el modal profundo.
- **Interactive Dossier:** Galería inmersiva en modales con efecto **Glass-Depth** (desenfoque dinámico de fondo) y contador digital de activos.
- **Smart Hybrid Navigation:** Cambio dinámico entre Píldora Superior (Desktop) y Dock Ergonómico (Mobile).

### 3. El Ecosistema "Go" (Master Plan v1.9.10)
- **Centralización SSO:** Unificación de identidad bajo Firebase Auth.
- **Pipeline Estratégico:** Sincronización transversal entre **RutaGo**, **AgroGo** y **CargoGo**.

## 🛠️ Stack Tecnológico Definitivo
- **Core:** React 18 + Vite + TypeScript.
- **Estilos:** Tailwind CSS (Optimización JIT).
- **Animaciones:** Framer Motion (Hardware Accelerated).
- **Backend:** Firebase (RTDB + Auth + Hosting).
- **PWA:** Vite Plugin PWA (Workbox).

## 🚀 Optimizaciones de Ingeniería
- **GPU-First Design:** Propiedades CSS que fuerzan la aceleración por hardware (`will-change`).
- **SVG Embedded Assets:** Texturas base64 para eliminar peticiones HTTP innecesarias.
- **Adaptive Visuals:** Protocolo `object-contain` en modales para visualización perfecta de capturas móviles y de escritorio.
