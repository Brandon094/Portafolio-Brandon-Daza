# Ficha Técnica - Ecosistema Digital Brandon Daza & ChopCode Solutions v5.5

## 🏗️ Arquitectura de Software (Nivel Senior Staff)

El proyecto ha evolucionado a un ecosistema multiplataforma unificado, optimizado para la máxima conversión y autoridad técnica.

### 1. MVVM & Progressive Web App (PWA)
- **Model:** Persistencia NoSQL en **Firebase Realtime Database** sincronizada mediante WebSockets.
- **Service Workers:** Implementación de `vite-plugin-pwa` para caché inteligente, carga instantánea y soporte fuera de línea.
- **PWA Manifest:** Configurado para modo `standalone`, permitiendo la instalación nativa en dispositivos iOS y Android con icono personalizado y tema dinámico.
- **ViewModel:** Capa de lógica desacoplada en Hooks para gestión de telemetría y estado de navegación.

### 2. Experiencia de Usuario "Elite" (UX/UI)
- **Violet Stealth System:** Estética minimalista basada en negro profundo, texturas de grano orgánico inyectadas vía SVG base64 (Zero-HTTP request).
- **Z-Axis Cinema Experience:** Navegación cinematográfica con factor de escala optimizado (15x) para fluidez absoluta (60 FPS).
- **Dossier Técnico (Modales):** Análisis arquitectónico profundo inyectado vía **React Portals** con scroll horizontal en títulos y acciones directas (Web/App).

### 3. El Ecosistema "Go" (Master Plan v1.9.10)
- **Centralización SSO:** Unificación de identidad bajo Firebase Auth.
- **Sincronización Transversal:** Capa de datos compartida entre RutaGo, AgroGo y CargoGo.

## 🛠️ Stack Tecnológico Definitivo
- **Core:** React 18 + Vite + TypeScript.
- **Estilos:** Tailwind CSS (Optimización JIT & Mesh Gradients).
- **Animaciones:** Framer Motion (Hardware Accelerated).
- **Backend:** Firebase (RTDB + Auth + Hosting).
- **PWA:** Vite Plugin PWA (Workbox).

## 🚀 Optimizaciones de Ingeniería
- **Zero-404 Asset Protocol:** Texturas y assets críticos embebidos en el bundle principal.
- **GPU-First Design:** Propiedades CSS que fuerzan la aceleración por hardware (`will-change`).
- **Mobile-First Audit:** Tipografía adaptativa y navegación orientada al pulgar (Bottom Dock).
- **Scroll Logic:** Reset atómico de posición en cambios de ruta SPA.
